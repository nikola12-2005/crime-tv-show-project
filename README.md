# Crime TV Show Project

A Django web app for browsing and managing a database of crime TV shows, built as a group project for CSC1025 with Rebecca Mc Hugh.

## Features

- Log in to access the site
- Home page with a list of crime TV shows
- Each show has a title, description, date, image, and rating
- Add a new show (for users with the right access)
- Delete existing shows
- Log out

## Tech stack

Python, Django, HTML, CSS, SQLite
